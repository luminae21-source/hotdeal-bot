전기히터 고르는 법 — 소비전력·발열 방식·가격 비교

전기히터를 소비전력(W)·발열 방식·가격으로 비교해요 · 가격은 매일 확인

결론

전기히터는 소비전력이 같아도 가격이 크게 달라요. 11월 8일 쿠팡 기준 브랜드마다 1개씩 고른 7종 중 상품 정보에 소비전력이 적힌 4종은 800W~2,000W였고, 같은 800W가 14,110원(모리츠)과 36,900원(BRUNO)으로 2.6배 차이 났어요. 쓸 곳 넓이와 소비전력(W÷1000 = 1시간 kWh), 발열 방식(석영관·카본·컨벡션)을 먼저 정한 뒤 가격을 비교하세요. 사용면적·타이머·안전 표기는 상세 페이지로 확인해요.

고르는 기준

기준설명
소비전력(W)부터 보기1시간 쓰면 W÷1000 kWh예요. 800W는 0.8kWh, 2,000W는 2kWh예요. 이번 7종 중 쿠팡 상품 정보에 W가 적힌 건 4종이라, 나머지는 상세 페이지 표기로 확인해요.
발열 방식 확인석영관·카본은 복사열 방식, 컨벡션은 공기를 데워 도는 대류 방식이에요. 상품 정보의 발열체 종류로 확인하고 같은 방식끼리 가격을 비교해요.
사용면적 표기쿠팡 상품 정보에 사용면적이 적힌 건 7종 중 1종(3.3㎡)뿐이었어요. 쓸 곳 넓이를 먼저 재고 상세 페이지·판매자 문의로 확인해요.
타이머·자동 꺼짐·KC 인증 표기타이머(유니맥스·홈플래닛)와 자동전원차단(대웅)이 상품 정보에 적혀 있었어요. 넘어짐 차단·KC 인증 표기는 상세 페이지에서 확인해요.
