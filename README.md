# 🔥 핫딜봇 (자동 수익형 텔레그램 채널)

뽐뿌·루리웹·클리앙 핫딜을 15분마다 수집 → 같은 딜은 하나로 → **Claude가 살 만한 딜만 골라 코멘트** → **✅ 없이 채널에 바로 게시**. 글에 상품 주소가 있으면(루리웹·클리앙) **링크프라이스 딥링크 API**로 승인된 몰(G마켓·옥션·롯데온·이마트·하이마트, 앞으로 승인되는 몰도 자동)은 상품 페이지 제휴 링크가 자동으로 붙고, 주소가 없으면(뽐뿌: GitHub 서버 차단) G마켓·롯데온은 **검색 제휴 링크**(🔎 OO에서 찾기).
쿠팡·토스·네이버처럼 링크를 손으로 만들어야 하는 몰은 채널 글 **사본이 내 텔레그램으로** 옴(쿠팡은 '🔗 파트너스 링크 만들기', 네이버는 '📋 상품명 복사'+'🔗 쇼핑커넥트 열기', 그 외 상품 주소를 알면 '🛒 상품 열기' 버튼 포함) → 원하면 제휴 링크를 **답장하거나 그냥 보내면 채널 글 버튼 교체** + 대가성 문구 자동(선택). 쿠팡 API 키(최종 승인 후)를 넣으면 쿠팡도 자동 + 매일 **골드박스 TOP5**.

## 세팅 (약 20분, 폰으로 가능)

### 1. 텔레그램
1. **@BotFather** → `/newbot` → 이름 정하기 → **토큰** 복사 → `TG_TOKEN`
2. 새 **채널** 만들기(공개, 예: `@jinwoo_hotdeal`) → 채널 관리자에 **방금 만든 봇 추가**(메시지 게시 권한) → `TG_CHANNEL` = `@채널아이디`
3. 내 봇 채팅방 들어가서 **`/start`** 한 번 (안 하면 봇이 나한테 못 보냄)
4. **@userinfobot** 에게 아무 말 → 나오는 숫자 ID → `TG_ADMIN_ID`

### 2. Claude API 키
- console.anthropic.com → 결제수단 등록 + 크레딧 $10 충전 → API Keys → 키 발급 → `ANTHROPIC_API_KEY`
- ⚠️ Claude Max 구독과 API 요금은 **별도**야

### 3. GitHub
1. 새 저장소 **Public**으로 생성 (5번 웹사이트를 무료로 쓰려면 공개 필요. 코드에 비밀값 없음, 키는 시크릿에만)
2. `Add file → Upload files` 로 `hotdeal.py`, `build_site.py`, `cards.py`, `test_hotdeal.py`, `README.md` 업로드
3. `Add file → Create new file` → 파일명에 **`.github/workflows/hotdeal.yml`** 입력 → `hotdeal.yml` 내용 붙여넣기 → Commit
4. `Settings → Secrets and variables → Actions → New repository secret` 로 4개 등록
   `TG_TOKEN`, `TG_ADMIN_ID`, `TG_CHANNEL`, `ANTHROPIC_API_KEY`
5. `Actions` 탭 → `hotdeal` → **Run workflow** → 채널에 딜이 올라오면 성공 🎉
   (0개면 6점 넘는 딜이 없던 것. 실행 로그 `점수` 줄에 딜별 점수가 나옴. ⚠️ 이제 채널에 바로 올라가므로 `MIN_SCORE=1` 테스트는 하지 말 것)

### 4. 쿠팡파트너스 (수익 연결)
1. partners.coupang.com 가입 → **활동 페이지에 링크를 거는 채널 전부 등록** (텔레그램·hotdealpick.kr·블로그·Threads·인스타. 미등록 채널에 링크 걸면 제재 가능)
2. **최종 승인**(누적 판매 15만원 이후) → 파트너스 사이트에서 **API 키(Access/Secret) 발급**
   - 승인 전 실적 쌓기(10/6~): 파트너스 '간편 링크'로 만든 **골드박스 링크**(`GOLDBOX`, link.coupang.com/a/hBMtMDCxFY)를 사이트 위쪽 버튼 + 매일 아침 7시 이후 채널 1회 게시 → 클릭 후 24시간 안 쿠팡에서 산 건 뭐든 실적. `[쿠팡]` 딜 사본에 파트너스 링크 답장하는 것도 실적에 바로 반영
   - 간편 링크 '추천 링크'(10/9 진우가 이름 붙여 보낸 것): 홈 `hHgmfLTIUm`(행사 글 기본 버튼 `CP_HOME`) · 골드박스 `hHgulARSQ8` · 로켓프레시 `hHgxjTMio8`(프레시 행사 버튼 `CP_FRESH`) · 로켓와우 `hHgBnsbMHY` · 로켓배송 `hHg2Ash7h6` · 로켓직구 `hHg6cgzceO` · 여성패션 `hHheNtwq4q` · 남성패션 `hHhirmOMRE` · 유아동패션 `hHiYnoeTg4` · 쿠팡트래블 `hHhlKTVJ7s` (모두 `https://link.coupang.com/a/` 뒤에 붙임, `events.json` 예약 글 버튼으로도 사용). 유아동패션은 진우가 다시 보내준 `hHiYnoeTg4`(앞서 온 `hHhj0pD41c`는 원래 주소 칸이 남성패션 링크라 안 씀). 처음 순서로만 받은 10개(`hG70…`~`hG8c…`)는 대신 안 씀
