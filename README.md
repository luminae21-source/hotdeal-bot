# 🔥 핫딜봇 (자동 수익형 텔레그램 채널)

뽐뿌·루리웹·클리앙 핫딜을 15분마다 수집 → 같은 딜은 하나로 → **Claude가 살 만한 딜만 골라 코멘트** → **✅ 없이 채널에 바로 게시**. 글에 상품 주소가 있으면(루리웹·클리앙) **링크프라이스 딥링크 API**로 승인된 몰(G마켓·옥션·롯데온·이마트·하이마트, 앞으로 승인되는 몰도 자동)은 상품 페이지 제휴 링크가 자동으로 붙고, 주소가 없으면(뽐뿌: GitHub 서버 차단) G마켓·롯데온은 **검색 제휴 링크**(🔎 OO에서 찾기).
쿠팡·토스·네이버처럼 링크를 손으로 만들어야 하는 몰은 채널 글 **사본이 내 텔레그램으로** 옴(쿠팡은 '🔗 파트너스 링크 만들기', 네이버는 '📋 상품명 복사'+'🔗 쇼핑커넥트 열기', 그 외 상품 주소를 알면 '🛒 상품 열기' 버튼 포함) → 원하면 제휴 링크를 **답장하거나 그냥 보내면 채널 글 버튼 교체** + 대가성 문구 자동(선택). 쿠팡 API 키(최종 승인 후)를 넣으면 쿠팡도 자동 + 매일 **골드박스 TOP5**.

```
GitHub Actions (15분마다 24시간 · 밤 0~8시 채널 글·사본은 알림 없이 무음 · tick 타이머가 15분마다 실행시킴 → 아래 7번)
 ├─ 관리자 입력 처리: 사본에 링크 답장(쿠팡·토스·네이버는 링크만 보내도 가장 최근 사본) → 채널 글 버튼 교체 / ✅·❌ 누른 초안 → 채널 게시
 ├─ 뽐뿌 RSS + 루리웹 핫딜 RSS + 클리앙 알뜰구매 목록 → 30분 지난 새 글(루리웹은 15분 · 뽐뿌 RSS는 15개뿐이라 바쁜 시간엔 다음 실행 전에 목록에서 밀려날 글도 바로) → 같은 상품은 하나만(24시간 안 이미 본·올린 딜 제외) → Claude 점수·코멘트·검색어 → 7점↑ **한 번에 최대 2개** 채널 바로 게시(넘친 딜은 15분 뒤 다시 판단)
 │    (글에서 쇼핑몰 상품 주소를 꺼냄(루리웹·클리앙은 GitHub 서버에서 됨, 뽐뿌는 차단) → 남의 제휴 링크는 원래 상품 주소로 풀고 → 링크프라이스 승인 몰 = 상품 페이지 제휴 링크(주소 없으면 검색 링크) / 쿠팡·네이버 등 = 관리자에게 사본 + '🛒 상품 열기' 버튼 / 게시 실패 = 초안)
 ├─ 쿠팡 골드박스: 키 없으면(최종 승인 전) 7시 이후 1회 **파트너스 링크로 채널에 바로** / 키 있으면 7시 이후 1회 **TOP5도 채널에 바로**(✅ 필요 없음)
 ├─ 21시 이후 1회 '오늘의 딜 모아보기' 초안 (✅ → 채널 게시) + 📝 블로그용 글 + 카드 이미지 생성 + 🎬 인스타 릴스 영상(점수 TOP3, 15초: 숫자 훅 → 딜마다 이모지·가격·'살 만한 이유' → 저장·공유 유도)을 관리자에게 전송
 ├─ 채널에 올라간 딜 → 사이트 딜 페이지가 뜨면(다음 실행) Threads에 딜마다 자동 게시 (3시간 지난 딜·모아보기 제외, 1회 최대 3개)
 ├─ 카드가 사이트에 올라오면(다음 실행) Threads 자동 게시 + 인스타용으로 관리자에게 전송
 └─ 채널에 게시된 딜 → 웹사이트 자동 갱신 (hotdealpick.kr)
```

## 세팅 (약 20분, 폰으로 가능)

### 1. 텔레그램
1. **@BotFather** → `/newbot` → 이름 정하기 → **토큰** 복사 → `TG_TOKEN`
2. 새 **채널** 만들기(공개, 예: `@jinwoo_hotdeal`) → 채널 관리자에 **방금 만든 봇 추가**(메시지 게시 권한) → `TG_CHANNEL` = `@채널아이디`
3. 내 봇 채팅방 들어가서 **`/start`** 한 번 (안 하면 봇이 나한테 못 보냄)
4. **@userinfobot** 에게 아무 말 → 나오는 숫자 ID → `TG_ADMIN_ID`

### 2. Claude API 키
- console.anthropic.com → 결제수단 등록 + 크레딧 $10 충전 → API Keys → 키 발급 → `ANTHROPIC_API_KEY`
- ⚠️ Claude Max 구독과 API 요금은 **별도**야

### 3. GitHub
1. 새 저장소 **Public**으로 생성 (5번 웹사이트를 무료로 쓰려면 공개 필요. 코드에 비밀값 없음, 키는 시크릿에만)
2. `Add file → Upload files` 로 `hotdeal.py`, `build_site.py`, `cards.py`, `test_hotdeal.py`, `README.md` 업로드
3. `Add file → Create new file` → 파일명에 **`.github/workflows/hotdeal.yml`** 입력 → `hotdeal.yml` 내용 붙여넣기 → Commit
4. `Settings → Secrets and variables → Actions → New repository secret` 로 4개 등록
   `TG_TOKEN`, `TG_ADMIN_ID`, `TG_CHANNEL`, `ANTHROPIC_API_KEY`
5. `Actions` 탭 → `hotdeal` → **Run workflow** → 채널에 딜이 올라오면 성공 🎉
   (0개면 7점 넘는 딜이 없던 것. 실행 로그 `점수` 줄에 딜별 점수가 나옴. ⚠️ 이제 채널에 바로 올라가므로 `MIN_SCORE=1` 테스트는 하지 말 것)

### 4. 쿠팡파트너스 (수익 연결)
1. partners.coupang.com 가입 → **활동 페이지에 링크를 거는 채널 전부 등록** (텔레그램·hotdealpick.kr·블로그·Threads·인스타. 미등록 채널에 링크 걸면 제재 가능)
2. **최종 승인**(누적 판매 15만원 이후) → 파트너스 사이트에서 **API 키(Access/Secret) 발급**
   - 승인 전 실적 쌓기(10/6~): 파트너스 '간편 링크'로 만든 **골드박스 링크**(`GOLDBOX`, link.coupang.com/a/hBMtMDCxFY)를 사이트 위쪽 버튼 + 매일 아침 7시 이후 채널 1회 게시 → 클릭 후 24시간 안 쿠팡에서 산 건 뭐든 실적. `[쿠팡]` 딜 사본에 파트너스 링크 답장하는 것도 실적에 바로 반영
3. 시크릿 2개 추가: `COUPANG_ACCESS_KEY`, `COUPANG_SECRET_KEY` → 다음 실행부터 **골드박스 TOP5 자동**(매일 7시 이후 1번 채널에 바로, 커뮤니티 추천·점수와 상관없음)
- 뽐뿌 `[쿠팡]` 딜은 뽐뿌 링크로 먼저 게시되고, 나한테 온 사본의 **'🔗 파트너스 링크 만들기'로 링크를 만들어 봇에 보내면** 채널 글 버튼이 교체됨 (뽐뿌가 GitHub 서버를 막아 쿠팡 주소를 못 읽기 때문. 아래 '매일 할 일'). 판매가 쌓여야 최종 승인 → 쿠팡 딜은 링크프라이스 경유보다 파트너스 직접 링크 권장
- 대가성 문구(`이 포스팅은 쿠팡 파트너스 활동의 일환으로…`)는 **제휴링크 글 맨 앞에 자동 삽입**됨

### 5. 웹사이트 (GitHub Pages, 무료)
- 저장소 **Public** 필요 (Free 플랜은 공개 저장소만 Pages 가능. 코드에 비밀값 없음, 시크릿은 별도 보관)
- `Settings → Pages → Source: Deploy from a branch → main / docs` → 저장
- 기본 주소 `https://luminae21-source.github.io/hotdeal-bot/` → 커스텀 도메인 **https://hotdealpick.kr** 연결됨 (가비아 DNS: A @ → 185.199.108~111.153, CNAME www → luminae21-source.github.io / Pages → Custom domain / `docs/CNAME`은 `build_site.py`가 매번 생성)
- 사이트 주소는 텔레그램 채널 설명과 쿠팡파트너스 **내 정보 → 웹사이트**에도 등록
- 검색 등록 완료: 구글 서치콘솔(DNS TXT 인증), 네이버 서치어드바이저(HTML 태그 — `build_site.py`의 `naver-site-verification` 메타, 지우면 소유확인 풀림)

### 6. Threads 자동 게시 (선택, 무료)
1. 브랜드용 인스타그램 계정 → Threads 앱 로그인 → 프로필 **공개**
2. developers.facebook.com → 내 앱 → **앱 만들기** → 사용 사례 **Threads API 액세스** → 이름 `hotdealpick`
3. 앱 대시보드 → **앱 역할 → 역할 → 사람 추가 → Threads 테스터** → 내 Threads 사용자명 → Threads 앱 **설정 → 계정 → 웹사이트 권한 → 초대 수락**
4. 사용 사례 → Threads API → **맞춤 설정**: 권한 `threads_basic`, `threads_content_publish` 추가 → 설정에 Redirect URI `https://hotdealpick.kr/` → **사용자 토큰 생성기**에서 테스터 토큰 생성 → 복사
5. GitHub 시크릿 `THREADS_TOKEN` 등록 → 끝 (완료)
- 올라가는 것: ① 채널에 올라간 **딜마다** 30분~1시간 뒤 Threads 글 1개 (제목·한 줄 코멘트·사이트 딜 페이지 링크·텔레그램 링크, 제휴 링크 딜이면 대가성 문구 맨 앞) ② 21시 모아보기 뒤 **오늘의 카드** 1장 ③ 9시 이후 **토스 하루특가 TOP5**(편성 있는 날, 쉐어링크·토스 대가성 문구 맨 앞)
- 링크는 사이트 딜 페이지(구매 버튼·대가성 문구 있음)로 걸어서, Threads 글에 쿠팡·링크프라이스 링크가 직접 들어가지 않음
- 토큰은 **60일 만료** → 봇이 "⚠️ Threads 게시 실패"(하루 1번) 보내면 4번 다시 해서 시크릿 교체
- 인스타 **카드 사진**은 자동화 안 함(인스타 API는 JPEG만 받음) → Threads 게시 후 **같은 카드를 봇이 채팅으로 보내줌** → 폰에서 인스타에 올리면 10초. 새 팔로워는 주로 **릴스**로 들어와서 21시 릴스 영상은 **자동 게시**(아래 6-2, 토큰 넣기 전엔 봇 채팅으로만)

### 6-2. 인스타 릴스 자동 게시 + 배경음악 (10/6~, 무료)
- **배경음악**: 인스타 '인기 음악'(유행곡)은 API로 못 넣음 → 상업적 이용 가능한 무료 음원을 영상에 섞음. Pixabay 음악(pixabay.com/music)에서 3~5곡 mp3 받기(곡 페이지에 Content ID 관련 안내가 있는 곡은 피하기 — 인스타가 저작권 곡으로 잡아 소리를 끌 수 있음) → **봇 채팅에 파일로 보내기** → '🎵 릴스 배경음악 등록' 답장. 날마다 돌아가며 사용, 15초보다 짧으면 반복, 앞뒤 페이드. 음원 파일은 공개 저장소에 안 올리고 텔레그램 file_id만 `music.json`에 저장(무료 음원도 원본 재배포는 금지라서). 등록 곡 없으면 지금처럼 무음
- **자동 게시 방식**: Facebook 로그인 방식(인스타가 페이스북 페이지 '핫딜픽'과 연결돼 있어서 가능) → 21시 영상 만들 때 인스타에 바로 업로드(영상 호스팅 불필요) → 인스타 처리가 끝나면 다음 실행(15분 안)에 발행 → 봇이 '🎬 인스타 릴스 자동 게시 완료'. 실패하면 '⚠️' 알림 + 영상은 그대로 봇 채팅으로 와서 직접 올리면 됨. 하루 1개라 인스타 한도(24시간 100개)와 무관
- **세팅(진우, 1번만)** — 페이스북은 **개인 프로필** 상태에서(페이지 프로필 '핫딜픽'으로 전환돼 있으면 개발자 화면이 오류남, 10/6). 메뉴 이름은 조금 다를 수 있음:
  1. developers.facebook.com/apps → `hotdealpick` 앱 → **사용 사례 추가** → 'Instagram에서 메시지 및 콘텐츠 관리' → **Facebook 로그인으로 API 설정**(이 앱에 추가가 안 되면 같은 사용 사례로 새 앱 `hotdealpick-ig`)
  2. developers.facebook.com/tools/explorer (그래프 API 탐색기) → 위 앱 선택 → 권한 `pages_show_list` `pages_read_engagement` `instagram_basic` `instagram_content_publish` 추가 → **Generate Access Token** → 페이지 '핫딜픽'·인스타 @hotdealpick.kr 선택·허용
  3. developers.facebook.com/tools/debug/accesstoken (토큰 디버거) → 2번 토큰 붙여넣기 → **액세스 토큰 연장**(60일 토큰)
  4. 탐색기에 3번 토큰을 넣고 `me/accounts?fields=name,access_token,instagram_business_account` 제출 → '핫딜픽'의 `access_token`(**페이지 토큰, 만료 없음**) → GitHub 시크릿 `IG_TOKEN`, `instagram_business_account`의 `id`(숫자) → 시크릿 `IG_USER_ID`

### 7. 15분 자동 실행 (tick 타이머, 무료·설정 완료)
GitHub 예약 실행(schedule)은 몇 시간씩 건너뛰어서, `tick.yml`이 스스로 15분 간격을 만듦.
1. `.github/workflows/tick.yml` 업로드 + `Settings → Environments → New environment` 이름 `tick` → **Wait timer 14분** → Save (완료, 10/6에 29 → 14)

## 경쟁 채널과 차별점 (10/5 조사)
- **핫딜 알림 서비스** (알구몬·핫구사·캐치딜 등): 커뮤니티 딜을 전부·키워드로 알려줌 → 양이 많고, 알구몬은 알림에 가격도 안 나와서 이용자 요청이 있음. 우리는 **하루 몇 개만 + 가격 + 한 줄 코멘트 + 단위가격**
- **가격 추적 앱** (폴센트·타이밍·역대가): 쿠팡 가격 그래프·평균가 대비 알림. 우리는 '추적'이 아니라 **"지금 살 만한지" 판단을 대신**해 줌 (평소가·최저가는 원글에 근거 있을 때만 말함)
- **SNS 쿠팡파트너스 계정** (Threads·인스타): 링크 도배·과장·불펌 영상이 많아 "소비자는 없고 공급자만"이라는 피로감. 쿠팡 공식 가이드도 과장·낚시 금지, 대가성 문구는 첫 부분에 링크와 함께
- **핫딜 모음 사이트** (핫딜아빠 hotdeal.dad, 10/5 조사): 40여 개 커뮤니티(뽐뿌·클리앙·루리웹·펨코·아카·퀘이사존·쿨앤조이·빠삭·딜바다·디시 갤러리 등) 글을 수 분마다 전부 모음 + 커뮤니티 필터·검색·**키워드 푸시 알림**(앱, 무료) + 카카오 오픈채팅. 수익 = 애드센스 + 링크프라이스 상품 딥링크('광고' 표시) + 쿠팡파트너스, 네이버 딜엔 링크 없음. 앱은 플레이스토어 다운로드 100+ 수준 → **앱까지는 안 만들어도 됨**(텔레그램이 우리 앱 역할). 배울 점 = 같은 딜을 여러 커뮤니티에서 모으되 **상품 페이지 주소로 직접 제휴 링크** → 우리도 루리웹·클리앙 추가 + 상품 페이지 딥링크로 반영(아래 검증 기록)

|---|---|
| `feed ppomppu ... 403` / `feed ruliweb_feed ...` / `feed clien_feed ...` | 그 출처만 막힌 것(나머지 출처는 계속 수집) → 알려주면 확인. 막힌 곳을 우회하지는 않음 |

| `TG sendMessage 403` | 봇에게 `/start` 안 보냄 |

| `deeplink ...` | 쿠팡 키 오타 / 아직 API 미승인 |
| `graph.threads.com ... API access blocked` | Meta가 개발자 계정을 잠금(10/6: '비정상적인 활동이 감지' → 계정 확인 요청) → 진우가 developers.facebook.com 접속 → **계정 확인** 단계 완료. 끝나면 다음 실행부터 자동 재개(토큰 그대로면 시크릿 수정 불필요). 확인 화면이 '기술적인 문제가 발생했습니다'면 페이스북이 **페이지 프로필(핫딜픽)로 전환된 상태** → 오른쪽 위 프로필 사진 → 개인 프로필로 전환 후 다시(10/6 실제로 이걸로 해결) |

| 구매 버튼이 커뮤니티 글로 감 | 뽐뿌 딜은 정상 (뽐뿌가 GitHub 서버 IP를 차단해 상품 주소를 못 꺼냄) → 링크프라이스 몰은 검색 링크, 그 외는 사본에 링크 답장으로 교체. 출처별 상태는 Actions → `linkcheck` → Run workflow → 로그에 쇼핑몰 주소가 나오면 정상 |
